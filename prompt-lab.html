THE CONCEPT: ROLE + CONTEXT + TASK + FORMAT
A vague prompt produces a vague answer. A good prompt has four parts: Role (who Claude should be), Context (your specific situation), Task (what you need), Format (how the answer should look). Each part makes the output sharply better.
